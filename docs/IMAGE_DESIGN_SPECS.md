```
Fuente: Poppins Bold
Color texto: #ffffff

```

## 💡 MEJORES PRÁCTICAS

### ✅ DO (Hacer)
- Usar contraste alto para legibilidad
- Incluir CTA claro y visible
- Agregar QR como alternativa
- Mantener diseño limpio y profesional
- Usar colores de marca consistentes
- Incluir beneficios claros (bullets)
- Hacer el premio visible/atractivo

### ❌ DON'T (No hacer)
- Sobrecargar con texto
- Usar más de 3 colores principales
- Poner URL muy larga
- Hacer QR muy pequeño (<120px)
- Usar fotos de stock genéricas
- Texto muy pequeño (<18px)
- Olvidar optimizar peso de imagen
